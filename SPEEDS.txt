tests (tests/testNNN); "configured" values from the firmware; "unverified" means not checked against a datasheet
or a measurement yet. Keep this file current when a test or a setting changes it.

2. Fixed clocks and timers
--------------------------

  K230 CPU timer (rdtime)       27 MHz (bsp/maix3/c908/tick.h, TIMER_CLK_FREQ)
  K230 watchdog                 20 s timeout, fed every 10 s by wdt_feed1 (priority 25), started at boot
  K230 PMU RTC                  32.768 kHz crystal Y1, restarts with the 1V8 rail (bug-003: R45 bridged)
  BL616 RTC (HBN)               32.768 kHz crystal Y3, runs through hibernate
  K230 heartbeat (K230_ALIVE)   toggles every 500 ms; the BL616 ends a session after 2 s without an edge
  BL616 link resend             300 ms without an ACK, 5 tries


3. Top speed if stable: what to raise and how it is accepted
------------------------------------------------------------

  Rule (user, 2026-10-21): every interface runs at its top supported setting if that is stable. A setting is
  adopted (Kconfig / defconfig / U-Boot, then this table) only after its stability test passes; otherwise the next
  step down is tried, and the reason is written here.

  Interface      Steps to try                     Stability test before adopting
  -------------  -------------------------------  ------------------------------------------------------------------
  DDR            2667 -> 3200 (HWODT, ALLODT)     test024 memtest >= 1 h at each, under KPU + encoder load; 10 cold
                                                  starts (each retrains); test025 temperature; test015 bandwidth
  SPI NAND       50 -> 66 -> 80 -> 100 MHz        test016: whole image area read-verified 10x, free-area write +
                 (RT-Smart and U-Boot/SPL each)   verify; 10 cold boots (SPL and U-Boot read the image too)
  UART link      115200 -> 230400 ... 2 Mbaud      test017: 10 MB both ways, 0 errors; both firmwares changed together
  AHT20 I2C      100 -> 400 kHz                   1000 reads, 0 CRC errors (cheap, so taken although it gains little)
  CPU, KPU, VPU  already at the top profile        CPU clock confirmed by test015's cycle count
  SDIO           at the top (50 MHz)              test014 (soak 109 MB, 0 errors)
  Cameras        when they arrive                 test020

  Notes: the DDR is inside the K230D package, so its signals never touch the PCB; the board's part is the rails and
  their decoupling under load (PDN), which the DDR soak exercises. Consoles and USB-C 1 stay as they are.
