tests (tests/testNNN); "configured" values from the firmware; "unverified" means not checked against a datasheet
or a measurement yet. Keep this file current when a test or a setting changes it.

2. Fixed clocks and timers
--------------------------

  K230 CPU timer (rdtime)       27 MHz (bsp/maix3/c908/tick.h, TIMER_CLK_FREQ)
  K230 watchdog                 20 s timeout, fed every 10 s by wdt_feed1 (priority 25), started at boot
  K230 PMU RTC                  32.768 kHz crystal Y1, restarts with the 1V8 rail (bug-003: R45 bridged)
  BL616 RTC (HBN)               32.768 kHz crystal Y3, runs through hibernate
  K230 heartbeat (K230_ALIVE)   toggles every 500 ms; the BL616 ends a session after 2 s without an edge
  BL616 link resend             300 ms without an ACK, 5 tries


3. What to raise, in order
--------------------------

  1. SPI NAND clock: 50 MHz of the chip's 104 MHz. Faster boot (image read), clip writes and reads. test025.
  2. UART link: only if test026 shows faster frames shorten a session.
  3. DDR, KPU: first check the K230D datasheet's maximum; measure (test024) before changing anything.
  Not worth it: AHT20 I2C (one read per 10 min, the 80 ms conversion dominates), consoles, USB-C 1.
