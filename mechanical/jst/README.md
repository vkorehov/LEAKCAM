# JST PH models (not in git)

The probe wires' connectors: S2B-PH-K-S on the board (S1-S3, LCSC C157932), mating PHR-2 housing
(C157955) with SPH-002T-P0.5S crimps (C111515).

JST's CAD data (https://www.jst-mfg.com/product/detail_e.php?series=199) is sent by e-mail after its
license form; the license forbids copying or disclosing it to third parties, so the files stay
local: put the received PHR-2 / S2B-PH-K-S STEP files and the SPH-002T-P0.5S drawing (2D PDF) in
this folder. Everything here except this README and .gitignore is ignored by git.
